# Universal Base64

A universal library for Base64 encoding and decoding, implemented in 12+ languages.

## Goal

The goal of this project is to provide a simple, consistent, and reliable Base64 implementation across a wide variety of programming languages. Each implementation will have the same API for encoding and decoding strings, and the output will be identical for the same input across all languages.

## Languages

*   C#
*   C++
*   Go
*   Java
*   JavaScript
*   Kotlin
*   PHP
*   Python
*   Ruby
*   Rust
*   Swift
*   TypeScript
